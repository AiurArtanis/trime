# Astra 9：拼音候选表情加入常用

日期：2026-09-25。

- Rime 候选提交到编辑器成功后，从提交文本提取 emoji，加入与表情面板相同的 `symbol_history` 文件。例如 `nu` 选中 `🤬` 后，打开“常用”即可看到。
- 普通汉字、拼音、数字及标点不会因候选提交而写入；混合文本只提取 emoji。不保存整段候选文本。
- 识别基础字符取自内置 `emoji_full`，组合规则保留变体选择符、肤色、旗帜、键帽、ZWJ 和标签旗帜。不依赖 Android 系统 Unicode 版本；未来内置表情集扩充时需同步基础字符表。
- 复用原有 180 条容量和最近使用排序，相同表情去重并置前。面板和候选使用先重新加载、再合并保存的文件锁操作，避免各自旧缓存覆盖另一方的新记录；重新打开常用页从文件刷新。
- 表情列表原有记录功能保留。输入连接不存在或提交失败时不添加候选表情；历史写入失败不阻断已经完成的文本上屏。

测试覆盖候选示例、混合文本过滤、重复 emoji、组合 emoji、两个历史实例交替写入、容量及重载持久性。没有三星实机 ADB 验证。
