# Astra 11：常用符号按使用频次排序

日期：2026-09-27。

问题原因：旧历史使用最近使用顺序，没有持久化次数；表情面板的 HISTORY 页点击还被排除在记录之外。

- 排序改为次数降序，同次数按最近使用顺序。候选上屏、表情面板和常用页点击都通过 `record` 累计，每次成功输入计一次。
- 常用页点击后不立即重排，以免连续点击误触；重新进入页面时重新加载最新排序。
- 文件升级为带版本头及次数的格式。旧列表每项按 1 次迁移，保留原有顺序，首次保存前生成 `symbol_history.legacy.bak`；历史次数无法追溯。
- 保留 180 条容量，满时仍淘汰最久未使用的项目。多个入口仍在同一锁下重新读取、合并、保存，避免次数相互覆盖。
- 测试覆盖频次优先、同频次最近优先、跨入口交替记录、重新加载、旧文件迁移及备份不变。
