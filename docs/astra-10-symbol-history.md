# Astra 10：拼音符号候选加入常用

用户已实机确认 astra-9 的拼音 emoji 收录正常。本版继续复用相同的上屏成功判断、历史合并、去重、容量和持久化机制。

- `dayu` 选中 `＞`、`wuxian` 选中 `∞` 后加入“常用”。
- 纯符号候选按 Unicode Symbol / Punctuation 分类收录，支持数学符号、箭头、货币和标点；忽略空白。组合标记附着在原符号上，emoji 优先按完整序列识别。
- 包含普通文字或数字的候选继续只提取 emoji，不从普通句子中收集逗号、句号等标点，避免污染常用列表。
- 新增测试覆盖用户两个示例、符号分类、去重、普通文本过滤和 emoji / 组合符号完整性。
